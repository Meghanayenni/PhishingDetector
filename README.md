# Phishing Email Detection Model

This is a cybersecurity mini-project that detects whether an email is phishing or safe using machine learning.

## Features

- Trains a machine learning model using Scikit-learn
- Uses TF-IDF feature extraction
- Classifies emails as Phishing or Safe
- Displays accuracy score
- Displays classification report
- Generates confusion matrix
- Saves trained model for future predictions

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Joblib
